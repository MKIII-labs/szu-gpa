# 深圳大学GPA计算器

基于命令行的深圳大学期末加权平均绩点计算工具，使用C语言编写

## ✨功能列表

- 支持自定义课程数量（最多 50 门）

- 输入百分制成绩和学分

- 输出前可修改任意课程的成绩或学分

- 自动换算绩点并显示等级（A+ 到 F）

- 输入错误时给出提示

- 计算加权平均绩点

## 绩点换算规则

以下换算标准依据《深圳大学本科生学籍管理规定》（或你的文件名）中绩点计算条目整理：

| 百分制成绩 | 课程绩点 | 等级 |
|:----------:|:--------:|:----:|
| 93-100     | 4.5      | A+   |
| 85-92      | 4.0      | A    |
| 80-84      | 3.5      | B+   |
| 75-79      | 3.0      | B    |
| 70-74      | 2.5      | C+   |
| 65-69      | 2.0      | C    |
| 60-64      | 1.0      | D    |
| 0-59       | 0        | F    |

> **数据来源**：深圳大学教务部官方文件《课程等级成绩、绩点与综合基本成绩的对照说明》（2015版）

## 加权平均规则

加权平均绩点 = Σ（课程绩点 × 课程学分） / Σ 课程学分

## 编译与运行

````bash

gcc -o gpa gpa.c
./gpa

```

## 注意事项

- 最大课程数为50
- 分数需为0到100间的整数
- 无法计算附加题情况
- 课程号从0开始
- 计算结果仅供参考，最终绩点请以教务系统为准！
